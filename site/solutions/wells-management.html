Solution · Wells

A single version of the truth for every well.

From real‑time virtual metering to regulatory well testing, Wells Management gives every discipline the same data — updated as often as every 30 seconds.

Module 01

E‑Well Book

Unparalleled flexibility for data integration — E‑Well Book consolidates corporate data from multiple applications into the single version of the truth for each well.

  • Interactive deviation visualization
  • Historical trending across all sources
  • Real‑time data overlaid with event data
  • Well operating envelopes
  • Observation logging
  • One‑click PDF reporting
Module 02

Virtual Metering

Twenty‑five years of engineering experience, embedded in a machine‑learning model that delivers real‑time oil, water and gas estimates for every well — every 30 seconds.

  • Topology layout with substations
  • Automatic header switching
  • Well‑test auto‑clipping
  • Reconciliation to export meter
  • Natural flowing, ESP, PCP, gas lift & beam pump wells
  • Injector well support
Module 03

EBM for Wells

Exception Based Management creates a single task list for each user, tracking field actions through a full human workflow — from flag to close‑out.

  • SLA visualization & compliance dashboards
  • Offline‑capable mobile app
  • Standardized diagnostic plots
  • Integration with Prosper & Lowis physical models
  • Data‑driven model support
Verified result: 98% of 7,500 wells across 12 types are monitored by EBS in a documented deployment — read the case study.
Module 04

P‑Q Curve

Built for optimizing gas production within your operating envelopes — monitoring gas well performance and flagging liquid loading, erosion and productivity impairment before they cost you volume.

Module 05

Well Test Planning, Control, Review & Auto Validation

A complete regulatory testing workflow: Planning auto‑generates monthly testing schedules from regulatory requirements; Control passes schedules to control systems for execution with operator override; Review embeds validation in a rich data‑review process; Auto Validation algorithmically checks new tests against well history — booked deferments, pump efficiency, BSW and gross/oil history — so engineers focus only on wells that are actually changing behavior.
